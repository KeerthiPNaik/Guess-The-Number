# Guess the Number Game

A fun browser-based number guessing game built using **HTML**, **CSS**, and **JavaScript**.

The computer selects a random number between 1 and 100, and the user must guess it in as few attempts as possible.


## Features

- Random number generation
- Real-time feedback:
  - If your guess is **higher than** or **lower than**
- Attempt counter
- Success message when guessed correctly
- Simple and responsive design


## How to Play

1. Open the game in your browser.
2. Enter your guess (1 to 100).
3. You'll get a hint:
   - "Taget is greater than number" if your number is greater than the target
   - "Taget is lesser than number" if your number is less
4. Keep guessing until you find the correct number!
5. The game will tell you how many attempts you used.
